DevConnect 🚀

DevConnect is an AI-powered social platform designed for developers and IT students to connect, share technical knowledge, discuss programming topics, and discover relevant content and users based on their interests and specializations.

✨ Features

- 👤 User Profiles — Technical profiles with specialization, bio, and external links.
- 📝 Posts — Create and share text, images, and code-based posts.
- 💬 Interactions — Comments, replies, reactions, follows, and saved posts.
- 🔍 Advanced Search — Search for people, posts, and technical tags with search history and suggestions.
- 🎯 Personalized Feed — Content recommendations based on user interests and previous interactions.
- 👥 User Recommendations — Suggest users based on technical specialization.
- 🔔 Notifications — Real-time push notifications for interactions, comments, follows, and other activities.
- 🔐 Account Management — Password change and OTP-based password recovery.
- 🌐 Content Translation — Translate posts and text into other languages.

🤖 AI Features

DevConnect integrates AI to assist users both when creating content and while browsing the platform.

Content Creation

- Post Generation — Generate a post from a given topic or idea.
- Professional Rewrite — Improve the clarity and professionalism of existing text while preserving its meaning.
- Tag Generation — Automatically generate relevant technical tags.
- Post Classification — Automatically classify posts as:
  - Question
  - Article
  - Information
  - Project

AI-Assisted Browsing

- Best Answer — Analyze answers to Question posts and identify the most useful answer.
- Post Summarization — Summarize long Article posts into a general idea and key points.
- Code Explanation — Provide a concise, high-level explanation of code included in posts.

🏗️ Architecture

DevConnect follows a client-server architecture where the React frontend communicates with the Django backend through REST APIs. The backend handles application logic, database operations, authentication, and communication with external services such as AI, notifications, email, and translation services.

🎨 UI/UX

The user interface and experience were designed using Figma, with a focus on creating a clean and user-friendly experience tailored to developers and IT students.

🚀 Deployment

- Frontend: Vercel
- Backend: Render
- Database: Neon PostgreSQL

🎓 Project

DevConnect was developed as a graduation project in Information Engineering, focusing on backend development with Django and the practical integration of AI-powered features into a social platform for developers.
